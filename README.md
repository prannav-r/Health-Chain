# Health-Chain MVP

A free, college-project MVP demonstrating health-data validation, blockchain hashes, patient consent, insurance premium calculation, claims, and wellness rewards.

## Repository structure

```text
health-chain/
├── AGENTS.md
├── context/
│   ├── project-overview.md
│   ├── architecture.md
│   ├── code-standards.md
│   ├── ai-workflow-rules.md
│   ├── ui-context.md
│   ├── progress-tracker.md
│   └── specs/
└── data/
```

## MVP principles

- Mock/generated health data only
- No paid APIs
- No production infrastructure
- No raw health data on-chain
- Ethereum Sepolia testnet only
- No real-money transfers
- Small, demo-friendly implementation

Start implementation with `context/specs/01-project-foundation.md`.
