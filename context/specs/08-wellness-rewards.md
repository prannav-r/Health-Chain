# Unit 08: Wellness Rewards

## Goal

Award simple wellness points based on validated health activity.

## Rules

- Steps >= 10000: +100 points
- Sleep >= 7 hours: +50 points
- Both conditions: +150 points

Avoid duplicate rewards for the same health record.

## Verify when done

- [ ] Valid activity produces the correct points.
- [ ] Invalid activity produces no reward.
- [ ] Duplicate processing does not double-award the same record.
- [ ] Points are visible on the patient dashboard.
