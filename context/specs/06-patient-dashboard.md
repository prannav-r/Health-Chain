# Unit 06: Patient Dashboard

## Goal

Create a patient-facing dashboard showing mock health metrics, validation, consent, blockchain status, and wellness points.

## Design

Use the UI tokens in `context/ui-context.md`.

## Implementation

Build:
- Patient selector
- Metric cards
- Source comparison
- Validation status
- Consent toggle
- Blockchain record panel
- Wellness points panel

Use backend APIs and blockchain integration where available.

## Verify when done

- [ ] Patient can be selected.
- [ ] Health metrics display.
- [ ] Validation status displays.
- [ ] Consent can be changed.
- [ ] Blockchain record is visible.
- [ ] Loading/error states work.
