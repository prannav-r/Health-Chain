# Unit 07: Insurance Workflow

## Goal

Create an insurance dashboard for viewing authorized patients, calculating premiums, and submitting/managing claims.

## Implementation

Build:
- Authorized patient list
- Policy card
- Premium calculation display
- Claim form
- Claims table
- Approve/reject controls for demo insurer workflow

Use smart-contract functions for the blockchain-backed state.

## Verify when done

- [ ] Only consented demo patients appear as authorized.
- [ ] Premium follows contract rules.
- [ ] Claim can be submitted.
- [ ] Claim status can change.
- [ ] UI clearly distinguishes pending/approved/rejected.
