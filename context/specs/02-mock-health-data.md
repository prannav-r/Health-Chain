# Unit 02: Mock Health Data

## Goal

Create realistic but fictional patient and health data and expose it through backend APIs.

## Implementation

Create `data/patients.json` and `data/health-records.json`.

Use three source labels:
- Mock Fitbit
- Mock Smartwatch
- Mock Phone

Provide endpoints for:
- patient list
- patient health records
- patient-specific source data

## Verify when done

- [ ] At least 3 demo patients exist.
- [ ] Each patient has multiple health records.
- [ ] Each comparable record has three mock sources.
- [ ] API returns JSON successfully.
- [ ] No real personal health information is used.
