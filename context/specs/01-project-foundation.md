# Unit 01: Project Foundation

## Goal

Create the basic Health-Chain repository structure with a React frontend, Node/Express backend, and Hardhat blockchain workspace.

## Design

Keep the repository simple and local-first.

## Implementation

### Root
Create:
- `frontend/`
- `backend/`
- `blockchain/`
- `data/`
- `context/`

### Frontend
Initialize React with Vite.

### Backend
Initialize Node.js + Express with a health check endpoint.

### Blockchain
Initialize Hardhat and create a placeholder contract/test structure.

## Dependencies

- react
- vite
- express
- hardhat
- ethers

## Verify when done

- [ ] Frontend starts locally.
- [ ] Backend starts locally.
- [ ] `GET /api/health` returns success.
- [ ] Hardhat compiles.
- [ ] No secrets are committed.
